⌚ Apple 健康同步：整體流程

手錶 → Garmin Connect → Apple 健康 →（iPhone 捷徑，每小時）→ 你的 Cloudflare 接收端 → App

大約需要 20–30 分鐘，只要設定一次。第 1、2 步用電腦比較方便，第 3～6 步在 iPhone 上做。
App 只會把「今天比平常多動的部分」加回 70% 到當天的額度（平常的活動量已經算在目標裡，避免重複計算）。

1產生同步密碼

  1. 打開 App →「設定」→「⌚ Apple 健康同步」。
  2. 按「產生」，會出現一串亂碼密碼。勾選「啟用 Apple 健康同步」，按「儲存並測試連線」（這時候會顯示連不到，正常，因為接收端還沒部署）。
  3. 按「複製密碼」，先貼到備忘錄，等一下第 2、5 步都會用到。不要分享給別人。

2部署接收端（GitHub）

  1. 到 GitHub 的 p0hsien1i.github.io repo →「Settings」→「Secrets and variables」→「Actions」→「New repository secret」。
  2. Name 填 HEALTH_SYNC_TOKEN，Secret 貼上第 1 步的密碼 →「Add secret」。
    （CLOUDFLARE_API_TOKEN 之前做留言系統時已經設定過，不用再加）
  3. 到 repo 的「Actions」分頁 → 左邊選「Deploy health worker」→ 右邊「Run workflow」→ 綠色「Run workflow」。
  4. 等 1～2 分鐘出現綠色勾勾 ✅。用瀏覽器打開 https://apo-health.pohsienbrianli.workers.dev，看到 {"ok":true,"service":"apo-health"} 就成功了。
  5. 回 App「設定」按一次「儲存並測試連線」，應該會顯示「連線成功」。

⚠️ 如果在「Find or create KV namespace」這步失敗：到 Cloudflare → My Profile → API Tokens，編輯留言系統用的那個權杖，確認有「Account → Workers KV Storage → Edit」權限，再重跑一次。

3讓 Garmin 寫入 Apple 健康

  1. 打開 Garmin Connect App →「更多」→「設定」→「已連結的應用程式」→「Apple 健康」。
  2. 確認已連結，而且「活動能量／卡路里」有允許寫入。
  3. 打開 iPhone「健康」App →「瀏覽」→「活動」→「活動能量」，應該看得到今天的數字。
    往下捲到「資料來源與取用」，記下 Garmin 的來源名稱（通常叫 Connect），第 4 步會用到。

4建立捷徑「Chef同步」

打開 iPhone「捷徑」App → 右上角「＋」→ 最上面把名稱改成 Chef同步（要一模一樣，App 裡的 🔄 按鈕會用這個名字）。然後依序加入以下動作（括號是英文介面的名稱）：

  1. 尋找健康樣本（Find Health Samples） 類型選「活動能量」，然後設定：
    ・加入篩選「開始日期」「在最近」15 天
    ・再加入篩選「來源」「是」Connect（第 3 步看到的 Garmin 來源，避免和 iPhone 自己算的重複）
    ・「分組方式」選 日（Group By：Day）
    ・排序依「開始日期」
  2. 重複每一個項目（Repeat with Each）對象是上一步的「健康樣本」。
  3. 在「重複」裡面加入 文字（Text）內容照這樣排（中間是半形等號 =，不要有空白）：
    ［重複項目的開始日期］=［重複項目的值］
    ・插入變數「重複項目」→ 點它 → 選「開始日期」→ 日期格式選「自訂」，填 yyyy-MM-dd
    ・再插入一次「重複項目」→ 點它 → 選「值」（Value，只要數字）
  4. 在「結束重複」之後加入 合併文字（Combine Text）對象是「重複結果」，合併方式選「新行」。
  5. 加入 取得 URL 的內容（Get Contents of URL）
    ・URL：https://apo-health.pohsienbrianli.workers.dev/sync
    ・展開「顯示更多」→ 方法選 POST
    ・標頭：新增一個，鍵 Authorization，值 Bearer 你的密碼（Bearer 後面有一個空白）
    ・要求本文選「檔案」，檔案選上一步的「合併的文字」
  6. （測試用）最後加一個 顯示結果（Show Result）按右下角 ▶ 執行，看到類似 {"ok":true,"received":15,...} 就成功了。第一次執行會問能不能讀取健康資料，請允許。測試成功後可以把「顯示結果」刪掉。

回 App 首頁，大圓環下方會出現「⌚ 今日活動 … kcal」。第一次會一起送最近 15 天，所以馬上就能算出你的「平常活動量」。

5設定「每小時」自動同步

iPhone 的自動化沒有「每小時重複」這個選項，所以用下面幾種觸發組合起來，效果就是每小時左右＋每次打開 App 前都會更新：

  1. 每小時（時間觸發）：「捷徑」→ 下方「自動化」→「＋」→「特定時間」→ 設 07:00、「每天」→ 選「立即執行」並關閉「執行時通知」→ 下一步選捷徑「Chef同步」。
    重複建立 08:00、09:00 … 23:00（想省事可以改成每 2 小時一個：07、09、11、13、15、17、19、21、23）。
  2. 手錶同步完就更新：「自動化」→「＋」→「App」→ 選「Connect」（Garmin Connect）、勾「已關閉」→「立即執行」→ 選「Chef同步」。
  3. 打開 App 前先更新：同上，App 選「Safari」、勾「已開啟」→「立即執行」→ 選「Chef同步」。
    （如果你是從主畫面圖示打開 App，就不需要這條；App 首頁的 🔄 按鈕可以隨時手動同步）

App 開著的時候也會每小時自動重新抓一次，從捷徑切回 App 時也會馬上更新。

6常見問題

  1. App 顯示「密碼不對」：捷徑標頭、App 設定、GitHub 的 HEALTH_SYNC_TOKEN 三個地方要是同一組。改了 GitHub 的密碼後要重跑一次「Deploy health worker」。
  2. 數字比 Garmin App 小：Garmin 會定時把手錶資料同步到手機，再寫進 Apple 健康，所以可能晚一點。打開 Garmin Connect 同步一下，再按 App 的 🔄。
  3. 數字好像重複算了：檢查第 4 步有沒有加「來源是 Connect」的篩選。
  4. 捷徑說「值」不是數字：在「文字」裡點「重複項目」時要選「值」，不要選整個健康樣本。
